# Evidências

Prints exigidos pelo enunciado, seção 6.3. Guardar aqui com estes nomes, que
são os referenciados no README e na documentação.

| Arquivo | O que deve mostrar |
|---|---|
| `resumo-da-esteira.png` | A aba *Summary* da execução #14, com as 8 etapas verdes |
| `esteira-completa.png` | A lista de jobs da execução #14, toda verde |
| `quality-gate-bloqueando.png` | A execução #1 ou #8, barrada por um gate |
| `aprovacao-producao.png` | A tela de aprovação do environment `producao` |
| `imagem-no-ghcr.png` | A imagem publicada, em *Packages* do repositório |
| `jogo-em-producao.png` | O jogo aberto em `cyber-guard-jogo.vercel.app` |

O print do gate bloqueando é o que demonstra que o controle **funciona** — vale
tanto quanto o da esteira verde. As execuções #1 a #13 têm vários exemplos, com
a causa de cada uma registrada em `../observacoes.md`.
